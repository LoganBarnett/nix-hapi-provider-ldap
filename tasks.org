* Project Overview

A standalone LDAP provider binary for [[https://github.com/LoganBarnett/nix-hapi][nix-hapi]].  The provider implements the
=Provider= trait from =nix-hapi-lib= and is spawned as a subprocess by the
nix-hapi reconciler.

Reference implementations to draw from:

- =~/dev/nix-hapi/crates/ldap= — LDAP implementation to port wholesale.
- =~/dev/nix-hapi/crates/fake= — Fake provider, useful for understanding the
  minimal Provider trait surface.
- =~/dev/nix-hapi/crates/ldap/tests/= — Integration tests to port, including
  the =TestLdapServer= harness that spins up a real =slapd= instance.

The crate is referenced via the nix-hapi GitHub mirror:
https://github.com/LoganBarnett/nix-hapi

*** Test harness

Port =tests/common/mod.rs= containing =TestLdapServer=:

- Spawns a real =slapd= process on a unique port (atomic counter for
  parallelism).
- Generates a minimal =slapd.conf= in a =tempfile::TempDir=.
- Locates OpenLDAP schemas via the =slapd= binary path (Nix-store-aware).
- =initialize()= creates =dc=test,dc=local=, =ou=users=, =ou=groups= OUs.
- =Drop= kills the process cleanly.

Ensure =slapd= (openldap) is available in =flake.nix= =devPackages=.
